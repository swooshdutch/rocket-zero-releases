# Rocket-Zero Racingleague

Official Windows downloads for Rocket-Zero Racingleague.

## Download and play

Open [Releases](https://github.com/swooshdutch/rocket-zero-releases/releases) and download the latest **RocketZero-Setup-VERSION.exe** from its Assets list. Run Setup, choose a drive and folder, then launch Rocket-Zero from its shortcut. No GitHub account is required to play.

Installed copies check for updates on launch. Choose **Update & restart** to install a new build, or **Not now** to keep playing. You can also check under **Settings > Updates**. Everyone in an online party must use the same game version.

## Your progress

Installed-game progress and custom tracks are kept in `%LOCALAPPDATA%\RocketZero\Player`. Remembered Discord authorization keeps its Windows-encrypted location under `%LOCALAPPDATA%\RocketZero\Discord`. Updates and uninstallation preserve player data.

Earlier portable ZIP copies keep their own `user_data` folder. See the installed game's README.txt before moving those saves.

## About this repository

This repository distributes compiled game installers, signed update metadata and release notes. **The game is not open source.** Game source code, development assets, private credentials and signing keys are not published here. Third-party licensing notices are included with the game.
